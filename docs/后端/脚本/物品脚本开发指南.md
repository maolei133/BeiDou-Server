# 物品脚本开发指南

## 1. 概述

物品脚本 (`item`) 用于定义当玩家使用特定消耗品时触发的自定义逻辑。这通常用于创建功能性的物品，例如随机宝箱、传送卷轴、特殊效果药水或打开 UI 界面的物品。

本指南将详细介绍如何编写物品脚本，并提供开发范本。

---

## 2. 脚本结构与入口函数

- **存放路径**: `scripts/item/`
- **文件名**: 脚本的文件名必须与物品的 ID 完全一致，例如 `2022060.js`。
- **核心对象**: `im` (`ItemScriptMethods`)
- **入口函数**: 脚本必须包含一个名为 `run` 的函数。当玩家双击使用该物品时，系统会自动调用此函数。

```javascript
/**
 * 玩家使用物品时执行的函数
 * @param {ItemScriptMethods} im - 物品脚本交互对象，提供了所有操作 API
 */
function run(im) {
    // 在这里编写你的逻辑
    // 脚本执行完毕后，通常需要消耗掉该物品
    im.gainItem(im.getItemId(), -1); 
    im.dispose();
}
```

**重要提示**: 物品脚本是一次性执行的。执行完毕后，您通常需要手动消耗掉该物品 (`im.gainItem(im.getItemId(), -1)`) 并调用 `im.dispose()` 来结束脚本会话。

---

## 3. 开发范本

### 范本1：随机金币宝箱

```javascript
function run(im) {
    // 生成 1000 到 10000 之间的随机金币
    const randomMeso = Math.floor(Math.random() * 9001) + 1000;
    
    im.gainMeso(randomMeso);
    im.getPlayer().dropMessage(5, "你打开了宝箱，获得了 " + randomMeso + " 金币！");
    
    // 消耗宝箱
    im.gainItem(im.getItemId(), -1);
    im.dispose();
}
```

### 范本2：随机传送卷轴

```javascript
function run(im) {
    const maps = [100000000, 101000000, 102000000, 103000000];
    const randomMap = maps[Math.floor(Math.random() * maps.length)];
    
    im.warp(randomMap, 0);
    
    // 消耗卷轴
    im.gainItem(im.getItemId(), -1);
    im.dispose();
}
```

## 4. API 接口列表

`im` (`ItemScriptMethods`) 对象继承自 `AbstractPlayerInteraction`，它提供了所有 `cm` 对象的基础 API，但没有自己专属的 API。

一个关键的常用方法是：
- `im.getItemId()`: 获取当前正在使用的物品的 ID。
