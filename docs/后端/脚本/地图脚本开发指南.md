# 地图脚本开发指南

## 1. 概述

地图脚本 (`map`) 用于定义当玩家与地图本身发生交互时触发的逻辑。这通常用于实现进入地图时的欢迎信息、特殊效果、剧情动画，或者在地图上停留时触发的周期性事件。

本指南将详细介绍如何编写地图脚本，并提供其专用的 API 接口。

---

## 2. 脚本结构与入口函数

- **存放路径**: `scripts/map/`
- **文件名**: 脚本的文件名必须与你在地图编辑器中为地图设置的脚本名称完全一致。
- **核心对象**: `ms` (`MapScriptMethods`)
- **入口函数**: 地图脚本可以包含多个预定义的入口函数，系统会在特定事件发生时自动调用它们。你只需要在脚本中实现你需要用到的函数即可。

### 常用入口函数

| 函数签名 | 说明 |
| :--- | :--- |
| `onFirstUserEnter(ms)` | 当天的第一个玩家进入这张地图时调用。 |
| `onUserEnter(ms)` | 每个玩家进入这张地图时都会调用。 |
| `onUserExit(ms)` | 每个玩家离开这张地图时都会调用。 |

## 3. 开发范本

### 范本1：玩家进入时显示欢迎信息

```javascript
// scripts/map/my_custom_map.js

/**
 * 每个玩家进入地图时调用
 * @param {MapScriptMethods} ms - 地图脚本交互对象
 */
function onUserEnter(ms) {
    const player = ms.getPlayer();
    ms.playerMessage(5, "欢迎来到 " + player.getMap().getMapName() + "！");
    
    // 检查玩家是否是 GM
    if (player.isGM()) {
        ms.playerMessage(6, "[GM 提示] 当前地图 ID: " + player.getMapId());
    }
}
```

### 范本2：播放剧情动画

```javascript
// scripts/map/aran_tutorial_map.js

function onUserEnter(ms) {
    // 调用一个在 MapScriptMethods.java 中预定义的 Java 方法
    ms.displayAranIntro(); 
}
```

## 4. API 接口列表

### 4.1 地图专用 API

| 方法签名 | 返回值 | 说明 |
| :--- | :--- | :--- |
| `ms.displayCygnusIntro()` | `void` | 根据当前地图ID，显示特定的女皇骑士团介绍动画。 |
| `ms.displayAranIntro()` | `void` | 根据当前地图ID，显示特定的战神教学动画。 |
| `ms.startExplorerExperience()` | `void` | 根据当前地图ID和玩家性别，显示冒险家职业介绍动画。 |
| `ms.goAdventure()` | `void` | 显示“去冒险”的剧情动画。 |
| `ms.goLith()` | `void` | 显示前往“明珠港”的剧情动画。 |
| `ms.explorerQuest(questId, questName)` | `void` | 为指定的勋章挑战任务更新进度。 |
| `ms.touchTheSky()` | `void` | 为“站在巅峰的人”勋章任务更新进度。 |
| `ms.lockUI()` | `void` | 锁定玩家的 UI 界面（通常在播放动画前调用）。 |
| `ms.unlockUI()` | `void` | 解锁玩家的 UI 界面。 |
| `ms.showInfoText(text)` | `void` | 在屏幕中央显示一个信息文本框。 |

### 4.2 通用 API 参考

`ms` (`MapScriptMethods`) 对象继承自 `AbstractPlayerInteraction`，因此它拥有所有 `cm` 对象的基础 API（如 `getPlayer`, `warp`, `haveItem` 等）。
