# 传送门脚本开发指南

## 1. 概述

传送门脚本 (`portal`) 用于定义玩家进入特定传送门时触发的自定义逻辑。这通常用于实现有条件的地图进入（如等级、任务、物品限制）、动态传送或触发特定效果。

本指南将详细介绍如何编写传送门脚本，并提供其专用的 API 接口。

---

## 2. 脚本结构与入口函数

- **存放路径**: `scripts/portal/`
- **文件名**: 脚本的文件名必须与你在地图编辑器中为传送门设置的脚本名称完全一致。
- **核心对象**: `pi` (`PortalPlayerInteraction`)
- **入口函数**: 脚本必须包含一个名为 `enter` 的函数。当玩家与传送门交互时，系统会自动调用此函数。

```javascript
/**
 * 玩家进入传送门时执行的函数
 * @param {PortalPlayerInteraction} pi - 传送门交互对象，提供了所有操作 API
 * @returns {boolean} - 返回 true 表示允许玩家通过，返回 false 表示阻止玩家通过
 */
function enter(pi) {
    // 在这里编写你的逻辑
    return true;
}
```

## 3. 开发范本

### 范本1：等级限制

```javascript
function enter(pi) {
    if (pi.getPlayer().getLevel() < 30) {
        pi.getPlayer().dropMessage(5, "你需要达到 30 级才能进入这个区域。");
        return false; // 阻止进入
    }
    
    // 允许进入，传送到目标地图的 "out00" 传送点
    pi.warp(101000000, "out00"); 
    return true;
}
```

### 范本2：任务完成状态检查

```javascript
function enter(pi) {
    // 检查任务 1234 是否已完成
    if (pi.isQuestCompleted(1234)) {
        pi.warp(910000000, 0); // 传送到自由市场
        return true;
    } else {
        pi.getPlayer().dropMessage(5, "你必须先完成前置任务才能进入。");
        // 播放音效并阻止进入
        pi.playPortalSound();
        return false;
    }
}
```

## 4. API 接口列表

### 4.1 传送门专用 API

| 方法签名 | 返回值 | 说明 |
| :--- | :--- | :--- |
| `pi.getPortal()` | `Portal` | 获取当前传送门的对象实例。 |
| `pi.runMapScript()` | `void` | 运行与此传送门同名的地图脚本（如果存在）。 |
| `pi.hasLevel30Character()` | `boolean` | 检查玩家账号下是否有30级以上的角色。 |
| `pi.blockPortal()` | `void` | 临时阻止玩家再次使用当前传送门。 |
| `pi.unblockPortal()` | `void` | 解除对当前传送门的阻止。 |
| `pi.playPortalSound()` | `void` | 播放默认的传送门音效。 |

### 4.2 通用 API 参考

`pi` (`PortalPlayerInteraction`) 对象继承自 `AbstractPlayerInteraction`，因此它拥有所有 `cm` 对象的基础 API（如 `getPlayer`, `warp`, `haveItem` 等）。
