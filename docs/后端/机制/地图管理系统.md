# 地图管理系统（MapManager / MapleMap / MapFactory）

## 一、架构概览

```
MapFactory (静态工具类)
    └── loadMapFromWz(id, world, channel, event)
         → 读取 WZ 文件 → 创建 MapleMap 实例

MapManager (每频道实例，Caffeine 缓存)
    ├── Cache<Integer, MapleMap>   ← 缓存所有已加载地图
    ├── getMap(id)                 ← 入口，懒加载
    ├── getDisposableMap(id)       ← 临时地图（不入缓存）
    ├── resetMap(id)               ← 失效旧实例，重新加载
    ├── pinMap(id) / unpinMap(id)  ← 常驻标记（阻止自动释放）
    ├── canDisposeMap(map)         ← 是否可释放（10 项条件）
    └── canAddDisposeMap(map)      ← 简版释放检查（无玩家/商人）

MapleMap (地图实例，每频道每地图一个)
    ├── 属性：地图 ID、世界、频道、边界、footholds、传送门……
    ├── 容器：characters, mapobjects, droppedItems, monsterSpawn……
    └── 定时任务：itemMonitor, expireItemsTask, mobSpawnLootTask, 人物属性更新
```

## 二、MapManager — 缓存管理

### 2.1 缓存配置

```java
// MapManager.java:60-96
this.cache = Caffeine.newBuilder()
    .maximumSize(2_000)                      // 最多缓存 2000 张地图
    .expireAfter(new Expiry<>())             // 过期策略
    .evictionListener(...)                   // 驱逐回调
    .build();
```

### 2.2 过期策略 (Expiry)

地图创建/更新/读取时评估过期时间：

```
resolveExpiry(map)
    ├─ map == null → true → 60s 宽限期
    ├─ pinnedMaps.contains(id) → false → Long.MAX_VALUE（永不过期）
    └─ canDisposeMap(map)
         ├─ true  → 60 秒宽限期（纳秒）
         └─ false → Long.MAX_VALUE（永不过期）
```

### 2.3 二次确认驱逐

```
到期 → evictionListener
    ├─ canDisposeMap(map) → false → return（跳过驱逐，map 丢弃，下次 getMap 重建）
    └─ canDisposeMap(map) → true  → map.dispose()
```

> 不满足条件的地图被驱逐后，对象被丢弃。下次 `getMap(id)` 会通过 `MapFactory.loadMapFromWz()` 重建全新实例。

### 2.4 缓存触摸（占用变化通知）

以下操作触发 `cache.put(id, map)` → `expireAfterUpdate` → 重新评估过期时间：

| 触发点 | 方法 | 评估后的效果 |
|--------|------|-------------|
| 玩家进入地图 | `MapleMap.addPlayer()` → `touchCache()` | 有人 → `Long.MAX_VALUE` |
| 玩家离开地图 | `MapleMap.removePlayer()` → `touchCache()` | 无人 → 60s 宽限期 |
| 商人上架 | `MapleMap.addMapObject(HIRED_MERCHANT)` → `touchCache()` | 有商人 → `Long.MAX_VALUE` |
| 商人下架 | `MapleMap.removeMapObject(HIRED_MERCHANT)` → `touchCache()` | 无商人 → 60s 宽限期 |

### 2.5 `canDisposeMap` — 释放条件（10 项）

```java
// MapManager.java:173-183
canDisposeMap(map):
    if null → true
    if pinnedMaps.contains(id) → false
    return map.getCharacterCount() == 0         // ① 无玩家
        && !map.hasHiredMerchants()             // ② 无雇佣商人
        && map.getDroppedItemCount() <= 0       // ③ 无掉落物品
        && map.countBosses() == 0               // ④ 无 BOSS 存活（后台刷新中的 BOSS 算）
        && map.getEventInstance() == null       // ⑤ 无事件实例
        && !map.isEventMap()                    // ⑥ 非活动地图(按ID范围)
        && !map.hasClock()                      // ⑦ WZ <clock> 属性为 false
        && !map.hasPendingBossSpawns();          // ⑧ 无待刷新 BOSS
```

### 2.6 关键方法

```java
getMap(int mapid)
    → cache.get(id, () -> MapFactory.loadMapFromWz(...))   // 懒加载

resetMap(int mapid)
    → cache.invalidate(id) + getMap(id)                    // 重置地图（清空状态）

getDisposableMap(int mapid)
    → MapFactory.loadMapFromWz(...)                         // 不入缓存，用完即弃

isMapLoaded(int mapId)
    → cache.getIfPresent(mapId) != null                      // 是否已加载

getMaps()
    → new HashMap<>(cache.asMap())                           // 当前所有缓存地图快照

updateMaps()
    → 遍历所有缓存地图，调用 map.respawn() + map.mobMpRecovery()

dispose()
    → cache.invalidateAll()                                  // 关服时清空
```

### 2.7 常驻标记（pinMap / unpinMap）

```java
pinMap(int mapId)
    → pinnedMaps.add(id)
    → cache.put(id, existing)      // 强制触发 expireAfterUpdate，重置为永不过期

unpinMap(int mapId)
    → pinnedMaps.remove(id)
```

## 三、MapleMap — 地图实例

### 3.1 字段一览

```java
// 标识

// 边界 & 物理

### 3.2 玩家生命周期

```
addPlayer(chr)                        removePlayer(chr)
    ├─ characters.add(chr)                ├─ characters.remove(chr)
    ├─ 组队处理                           ├─ touchCache()
    ├─ 广播 enterField 封包               ├─ 广播 removePlayer 封包
    ├─ event 注册                         ├─ 事件退出
    ├─ OnUserEnter 脚本                   └─ 清理
    ├─ 时钟/船/物品刷新同步
    └─ touchCache()
```

### 3.3 地图对象（MapObject）

```
mapobjects.put(objectId, obj)

类型枚举 (MapObjectType):
    NPC, MONSTER, PLAYER, ITEM, SUMMON, MIST,
    DOOR, REACTOR, SHOP, HIRED_MERCHANT, PLAYER_NPC,
    DRAGON, KITE, EXTRACTOR

addMapObject(obj)        → 分配 OID + touchCache（HIRED_MERCHANT 时）
removeMapObject(oid)     → touchCache（HIRED_MERCHANT 时）

## 五、刷怪系统

### 5.1 SpawnPoint（刷怪点）

```java
// gms-server/src/main/java/org/gms/server/life/SpawnPoint.java
class SpawnPoint {
    monster         // 怪物 ID
    mobTime         // 刷新间隔（秒），-1 = 不刷新
    team            // 阵营
    pos / fh / f    // 位置和朝向
    nextPossibleSpawn  // 下次可以刷新的时间戳
    mobInterval     // 刷新延迟（毫秒），默认 5000
    spawnedMonsters // 当前已刷数量 AtomicInteger
    immobile        // 是否不移动
    denySpawn       // 禁止刷新
    shouldPersist   // 是否持久化刷新时间到数据库（BOSS）
    shouldId        // 数据库 BOSS 调度 ID
    msgRebirth / msgDeath  // 重生/死亡消息
}
```

### 5.2 刷怪触发器

```
MapManager.updateMaps()      ← TimerManager（定期调用）
    └── map.respawn()
          ├── BOSS 刷怪点 → shouldSpawn? → spawnMonster
          └── 普通刷怪点 → 根据玩家数计算应出数量 → 随机挑选刷怪点 → spawnMonster

MapleMap.spawnMonster(monster)
    ├─ 检查 BOSS 容量限制
    ├─ 生成怪物 → 检查掉线保护
    ├─ 设置 buff → 设置控怪
    ├─ 设置怪物监听器（SpawnPoint 的 monsterKilled 回调）
    ├─ addMapObject(monster)
    └─ 广播 spawnMonster 封包

MapleMap.respawn()
    ├─ if (!allowSummons) return
    ├─ if (getCharacterCount() == 0) return  ← 无人时不刷怪
    ├─ BOSS 优先：遍历 monsterSpawnBoss
    ├─ 计算应出：getNumShouldSpawn(numPlayers)
    │    └─ 基于 monsterSpawn 大小 × 当前 spawnRate × 玩家数修正
    └─ 普通：随机打乱 monsterSpawn → 跳过 BOSS → 取 shouldSpawn → spawnMonster
```

### 5.3 `shouldSpawn()` 条件

```java
// SpawnPoint.java:80-85
shouldSpawn():
    if denySpawn        → false
    if mobTime < 0      → false（WZ 设置 mobTime = -1 = 该刷怪点被禁用）
    if spawned > 0      → false（该点已有存活怪物）
    return nextPossibleSpawn <= currentTime
```

### 5.4 怪物杀死回调

```java
monsterKilled(killer):
    spawnedMonsters.decrementAndGet()
    mobTime == -1 → 不重生
    mobTime == 0  → nextPossibleSpawn = now + mobInterval（立即准备重生）
    mobTime > 0   → nextPossibleSpawn = now + mobTime * 1000
    if BOSS && shouldPersist → 更新 BossScheduleService（数据库持久化下次刷新时间）
```

### 5.5 实例地图刷怪

```java
instanceMapRespawn()          // 事件地图：补充不足数量
instanceMapForceRespawn()     // 事件地图：强制刷新
    → 基于 monsterSpawn.size - spawnedMonstersOnMap
```

## 六、地图定时任务

| 任务 | 间隔 | 作用 |
|------|------|------|
| `respawn()` | 由 `MapManager.updateMaps()` 调度 | 刷怪 |
| `mobMpRecovery()` | 由 `MapManager.updateMaps()` 调度 | 怪物 MP 恢复 |
| `itemMonitor` | 500ms | 地面物品超时销毁 + 保护 |  
| `expireItemsTask` | 由配置 `item_expire_check` 设定 | 过期物品清理 |
| `mobSpawnLootTask` | 200ms | 怪物掉落动画延迟生成 |
| `characterStatUpdateTask` | 200ms | 执行注册的属性更新 Runnable |
| `moveLiveMonsters` | 按配置 | 怪物移动/逃跑监测 |

## 七、地图释放流程总结

```
时间线
│
├─ T0: 地图创建 (getMap → miss → loadMapFromWz)
│    └─ resolveExpiry → 60s（若空地图）
│
├─ T10: 玩家进入 (addPlayer → touchCache)
│    └─ resolveExpiry → Long.MAX_VALUE（永不过期）
│
├─ T60: （无定时器到期——因为被续期了）
│
├─ T70: 最后玩家离开 (removePlayer → touchCache)
│    └─ resolveExpiry → 60s
│
├─ T130: 60s 后到期
│    └─ evictionListener → canDisposeMap
│         ├─ true  → map.dispose() ✅
│         └─ false → 跳过（说明中途有玩家/商人回来过）
│
└─ 关服: dispose()
     └─ cache.invalidateAll() → 全部 eviction → 全部 dispose
```
