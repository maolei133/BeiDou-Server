# 日志系统使用说明

## 概述

新的日志系统（logsystem）是对原有日志系统的完全重构，提供了更高效、更灵活的日志记录和管理能力。

## 核心特性

- **动态分类管理** - 支持在运行时添加和修改日志分类
- **性能分级处理** - 高频/中频日志异步处理，低频日志同步处理
- **标准JSON格式** - 所有日志统一为标准JSON格式存储
- **自动上下文注入** - 自动填充账号、角色、IP等信息
- **实时监控** - 提供QPS、延迟、成功率等实时监控数据
- **REST API** - 完整的HTTP API接口支持

## 快速开始

### 1. 基础日志记录

```java
@Autowired
private IGameLogger gameLogger;

// 简单日志
gameLogger.log("player", "login", "玩家登录成功");

// 带自定义数据的日志
String customData = "{\"level\": 1, \"exp\": 100}";
gameLogger.logWithContext("player", "levelup", "玩家升级", customData);
```

### 2. 上下文管理

```java
// 创建上下文
GameLogContext context = gameLogger.createContext();

// 设置上下文信息
context.setAccountId(2);
context.setAccountName("magical");
context.setCharacterId(2);
context.setCharacterName("Magical");
context.setIpAddress("127.0.0.1");
context.setHardwareId("B6770000");
context.setMapId(980010020);
context.setMapName("竞技场出口");

// 设置为当前上下文
gameLogger.setCurrentContext(context);

// 之后的日志会自动使用此上下文信息
gameLogger.log("player", "login", "玩家登录");

// 清除上下文
gameLogger.clearCurrentContext();
```

### 3. 异常日志

```java
try {
    // 业务代码
} catch (Exception e) {
    gameLogger.logException("system", "error", "发生系统错误", e);
}
```

### 4. 批量日志

```java
GameLogEntry[] entries = new GameLogEntry[2];
entries[0] = GameLogEntry.builder()
    .majorCategory("item")
    .minorCategory("acquire")
    .message("玩家获得物品")
    .performanceLevel("MEDIUM")
    .build();
entries[1] = GameLogEntry.builder()
    .majorCategory("item")
    .minorCategory("use")
    .message("玩家使用物品")
    .performanceLevel("MEDIUM")
    .build();

gameLogger.logBatch(entries);
```

### 性能等级

- **HIGH（高频）** - 异步处理，延迟要求低（< 5ms）
- **MEDIUM（中频）** - 异步处理，适中延迟（5-20ms）
- **LOW（低频）** - 同步处理，低优先级

## 配置

### 基础配置

```java
@Autowired
private LogConfig logConfig;

logConfig.setEnabled(true);                    // 启用日志系统
logConfig.setRetentionDays(30);                // 日志保留天数
logConfig.setFileSizeMB(100);                  // 单个文件大小
logConfig.setCompressionEnabled(true);         // 启用压缩
logConfig.setAsyncThreadPoolSize(4);           // 异步线程数
```

### 性能分级配置

```java
// 高频日志配置
logConfig.setHighFreqBufferSize(2048);
logConfig.setHighFreqFlushInterval(500);

// 中频日志配置
logConfig.setMediumFreqBufferSize(1024);
logConfig.setMediumFreqFlushInterval(1000);

// 低频日志配置
logConfig.setLowFreqBufferSize(512);
logConfig.setLowFreqFlushInterval(5000);
```

## AOP切面自动注入

使用`@AutoLogContext`注解自动管理日志上下文：

```java
@Service
public class PlayerService {
    @Autowired
    private IGameLogger gameLogger;

    @AutoLogContext
    public void playerLogin(int accountId, String accountName) {
        // 该方法执行时会自动创建和清理日志上下文
        gameLogger.log("player", "login", "玩家登录成功");
    }
}
```

## 监控和统计

### 获取监控数据

```java
@Autowired
private LogMonitor logMonitor;

// 获取系统级统计
LogMonitor.LogStats systemStats = logMonitor.getSystemStats();
System.out.println("QPS: " + systemStats.getQPS(1000));
System.out.println("平均延迟: " + systemStats.getAverageLatency());
System.out.println("成功率: " + systemStats.getSystemSuccessRate());

// 获取分类级统计
Collection<LogMonitor.LogStats> categoryStats = logMonitor.getAllCategoryStats();
for (LogMonitor.LogStats stats : categoryStats) {
    System.out.println(stats.getCategoryId() + ": QPS=" + stats.getQPS(1000));
}

// 获取监控汇总
String summary = logMonitor.getSummary();
System.out.println(summary);
```

## 常见问题

### Q: 如何添加新的日志分类？

```java
@Autowired
private DynamicCategoryManager categoryManager;

categoryManager.registerCategory("custom", "event", "自定义事件", "HIGH");
```

### Q: 如何启用/禁用日志分类？

```java
categoryManager.setEnabled("player", "login", false);  // 禁用
categoryManager.setEnabled("player", "login", true);   // 启用
```

### Q: 如何设置分类输出选项？

```java
// 设置输出到控制台和文件
categoryManager.setOutputOptions("player", "login", true, true);

// 仅输出到文件
categoryManager.setOutputOptions("player", "login", false, true);

// 仅输出到控制台
categoryManager.setOutputOptions("player", "login", true, false);
```

### Q: 上下文会自动清理吗？

是的，日志系统会自动清理5分钟以上未使用的上下文，避免内存泄漏。

## 性能建议

1. **高频日志** - 使用MEDIUM或HIGH等级，充分利用异步处理
2. **批量日志** - 使用logBatch()方法记录多条相关日志
3. **上下文复用** - 在同一业务流程中复用同一上下文
4. **监控数据** - 定期清理监控数据以节省内存

## 注意事项

- 不要在高频操作中进行同步日志记录
- 避免在日志消息中包含大型对象
- 定期检查日志磁盘空间
- 为不同的业务场景使用不同的分类

## 故障排查

### 日志未记录

1. 检查分类是否启用：`categoryManager.getCategory("major", "minor")`
2. 检查上下文是否正确：`gameLogger.getCurrentContext()`
3. 查看应用日志是否有错误信息

### 性能下降

1. 检查异步队列大小：`gameLogger.getQueueStats()`
2. 调整线程池大小：`logConfig.setAsyncThreadPoolSize()`
3. 增加缓冲区大小：`logConfig.setHighFreqBufferSize()`
