# 日志系统文件结构说明

## 核心模块

### core 包
- `GameLogEntry.java`: 游戏日志实体类，定义日志的基本结构
- `HighPerformanceLogger.java`: 高性能日志记录器，负责高效的日志写入
- `HybridLogger.java`: 混合日志记录器，结合多种记录方式
- `LogEvent.java`: 日志事件定义
- `SimpleLogger.java`: 简单日志记录器实现

### config 包
- `LogConfig.java`: 基础日志配置类
- `PacketLogConfig.java`: 网络封包日志配置
- `LogProperties.java`: 日志属性配置
- `ConfigurationManager.java`: 配置管理器
- `LogConfigManager.java`: 日志配置管理器
- `ConfigChangeEvent.java`: 配置变更事件
- `ConfigChangeListener.java`: 配置变更监听器
- `ConfigChangeNotifier.java`: 配置变更通知器
- `ConfigPersistenceService.java`: 配置持久化服务

### context 包
- `GameLogContext.java`: 游戏日志上下文
- `GameLogContextHolder.java`: 日志上下文持有者
- `LogContextManager.java`: 日志上下文管理器

### category 包
- `DynamicCategoryManager.java`: 动态分类管理器
- `CategoryRegistry.java`: 分类注册器
- `CategoryInfo.java`: 分类信息

### file 包
- `LogFileManager.java`: 日志文件管理器

### alert 包
- `LogAlertService.java`: 日志告警服务
- `AlertRuleManager.java`: 告警规则管理器
- `AlertRule.java`: 告警规则定义
- `AlertHistory.java`: 告警历史记录

## 功能模块

### api 包
- `IGameLogger.java`: 日志记录接口
- `GameLoggerImpl.java`: 日志记录接口实现

### aop 包
- `LogContextAspect.java`: 日志上下文切面

### annotation 包
- `LogCategory.java`: 日志分类注解
- `LogField.java`: 日志字段注解
- `AutoLogContext.java`: 自动日志上下文注解

### facade 包
- `SecurityLoggerFacade.java`: 安全日志门面

### formatter 包
- `GameLogFormatter.java`: 游戏日志格式化器

### util 包
- `LogFieldUtils.java`: 日志字段工具类

### cache 包
- `QueryCacheService.java`: 查询缓存服务

### query 包
- `LogQueryService.java`: 日志查询服务
- `LogQueryRequest.java`: 日志查询请求
- `LogQueryResult.java`: 日志查询结果
- `LogStatistics.java`: 日志统计信息

### monitor 包
- `LogMonitor.java`: 日志监控器
- `PerformanceAnalyzer.java`: 性能分析器
- `PerformanceMetricsCollector.java`: 性能指标收集器
- `AlertRuleService.java`: 告警规则服务
- `MonitorDataService.java`: 监控数据服务

### analysis 包
- `LogAnalysisService.java`: 日志分析服务

### backup 包
- `LogBackupService.java`: 日志备份服务
- `BackupManager.java`: 备份管理器
- `BackupMetadata.java`: 备份元数据
- `BackupStrategy.java`: 备份策略

### index 包
- `LogIndexService.java`: 日志索引服务
- `LogIndexManager.java`: 日志索引管理器

### schedule 包
- `LogScheduleService.java`: 日志调度服务

### rest 包
- `Response.java`: REST响应封装
- `LogRecordRequest.java`: 日志记录请求
- `CategoryQueryRequest.java`: 分类查询请求
- `MonitorQueryRequest.java`: 监控查询请求

## 配置类
- `LogsAutoConfiguration.java`: 日志系统自动配置类，负责初始化各种日志组件
