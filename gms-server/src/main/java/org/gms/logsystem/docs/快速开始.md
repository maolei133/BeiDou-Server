## 后端集成步骤

### 1. 确认依赖已添加
在`pom.xml`中确认以下依赖已存在：
```xml
<!-- Spring AOP -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aop</artifactId>
</dependency>

<!-- AspectJ -->
<dependency>
    <groupId>org.aspectj</groupId>
    <artifactId>aspectjrt</artifactId>
</dependency>
<dependency>
    <groupId>org.aspectj</groupId>
    <artifactId>aspectjweaver</artifactId>
</dependency>
```

### 2. 自动配置验证
日志系统会通过`LogsAutoConfiguration`自动装配，无需手动配置。

启动应用后，控制台会输出：
```
[日志系统] 已初始化45个预定义日志分类...
[日志系统] LogsAutoConfiguration已加载...
```

### 3. 验证API接口
启动应用后，访问以下URL验证：
```
GET http://localhost:8080/api/logsystem/health
```

应返回200状态码和JSON响应。

## 基础使用示例

### 示例1: 简单日志记录
```java
@RestController
public class PlayerController {
    @Autowired
    private IGameLogger gameLogger;

    @PostMapping("/api/player/login")
    public Response<String> login(@RequestBody LoginRequest request) {
        // 记录登录日志
        gameLogger.log("player", "login", "玩家登录成功");
        return Response.success("登录成功");
    }
}
```

### 示例2: 带上下文的日志记录
```java
@RestController
public class PlayerController {
    @Autowired
    private IGameLogger gameLogger;

    @PostMapping("/api/player/logout")
    public Response<String> logout(@RequestParam int accountId, 
                                   @RequestParam String accountName) {
        // 创建上下文
        GameLogContext ctx = gameLogger.createContext();
        ctx.setAccountId(accountId);
        ctx.setAccountName(accountName);
        gameLogger.setCurrentContext(ctx);

        // 记录退出日志
        gameLogger.log("player", "logout", "玩家登出");

        // 清理上下文
        gameLogger.clearCurrentContext();
        
        return Response.success("登出成功");
    }
}
```

### 示例3: 带自定义数据的日志
```java
@RestController
public class ItemController {
    @Autowired
    private IGameLogger gameLogger;

    @PostMapping("/api/item/acquire")
    public Response<String> acquireItem(@RequestBody ItemRequest request) {
        String customData = "{\"itemId\": " + request.getItemId() 
                          + ", \"quantity\": " + request.getQuantity() + "}";
        
        gameLogger.logWithContext("item", "acquire", 
                                 "玩家获得物品", customData);
        
        return Response.success("获得物品成功");
    }
}
```

### 示例4: 前端页面基础使用
```vue

```

## 常见配置

### 修改日志输出目录
编辑应用配置文件（`application.yml`或`application.properties`）：
```yaml
game:
  log:
    dir: /var/logs/game
    retention-days: 30
    file-size-mb: 100
    compression-enabled: true
```

### 调整性能分级参数
在`LogConfig`类中修改默认值：
```java
// 高频日志
private int highFreqBufferSize = 2048;      // 缓冲区大小
private int highFreqFlushInterval = 500;    // 刷新间隔(ms)

// 中频日志
private int mediumFreqBufferSize = 1024;
private int mediumFreqFlushInterval = 1000;

// 低频日志
private int lowFreqBufferSize = 512;
private int lowFreqFlushInterval = 5000;
```

### 添加自定义分类
```java
@Autowired
private DynamicCategoryManager categoryManager;

public void initCustomCategories() {
    categoryManager.registerCategory("custom", "event", 
                                   "自定义事件", "MEDIUM");
}
```

## 常见问题排查

### Q1: 访问API返回404
**原因**: 应用未正确启动或REST控制器未加载

**解决**: 
1. 检查应用是否正确启动
2. 查看启动日志是否有错误信息
3. 确认`LogController`和`ConfigController`已被扫描

```bash
mvn clean compile
java -jar your-app.jar
# 查看日志输出中是否有 "Mapped" 信息
```

### Q2: 前端页面白屏
**原因**: 路由未正确配置或API请求失败

**解决**:
1. 检查浏览器控制台(F12)中的JavaScript错误
2. 检查网络标签页中的API请求是否返回200
3. 确认`logs.ts`中的API基础URL正确

```typescript
// logs.ts中确认
const baseURL = '/api/logsystem'  // 应与后端路径匹配
```

### Q3: 日志未记录
**原因**: 分类未启用或日志等级不匹配

**解决**:
1. 在配置页面检查分类是否已启用
2. 检查应用日志级别配置
3. 验证日志实际输出位置

```bash
# 查看日志输出
tail -f /var/logs/game/application.log
```

### Q4: 性能监控数据为0
**原因**: 监控数据收集有延迟

**解决**:
1. 先进行一些日志记录操作
2. 等待10秒左右
3. 刷新监控页面
4. 或点击"刷新"按钮

## 性能调优建议

### 1. 日志写入性能优化
```java
// 使用异步日志处理
gameLogger.log("player", "login", "玩家登录");  // 自动异步

// 对于低频日志，同步记录也可接受
gameLogger.log("system", "error", "系统错误");  // LOW频，同步
```

### 2. 内存优化
```java
// 定期清理监控数据
monitor.clearData();

// 调整队列大小
logConfig.setAsyncQueueSize(5000);  // 默认10000
```

### 3. 磁盘空间管理
```yaml
game:
  log:
    retention-days: 7      # 减少保留天数
    compression-enabled: true  # 启用压缩
    file-size-mb: 50       # 减小单文件大小
```

### 4. 网络包日志优化
```java
// 屏蔽高频包，减少日志量
categoryManager.addInPacketBlock(0x00);  // 屏蔽心跳包
categoryManager.addInPacketBlock(0x01);  // 屏蔽其他包
```

## 监控告警建议

### 重点监控指标
1. **QPS**: 如果超过1000，需要优化
2. **成功率**: 如果低于99%，需要排查错误
3. **平均延迟**: 如果超过10ms，需要性能优化
4. **队列深度**: 如果接近缓冲区大小，需要调整参数

### 告警规则建议
```javascript
// 在LogMonitor页面中添加规则
const alertRules = [
  { metric: 'qps', threshold: 1000, level: 'warning' },
  { metric: 'successRate', threshold: 95, level: 'error' },
  { metric: 'avgLatency', threshold: 10, level: 'warning' },
  { metric: 'queueDepth', threshold: 1800, level: 'error' }
];
```
