# 日志系统前端测试指南

## 1. 页面访问

访问日志系统主页面：`http://localhost:8080/game/logs`

## 2. 页面结构

### 2.1 导航栏（顶部）
- **紫色渐变背景**：整体品牌色设计
- **三个导航选项**：
  - 🔧 **配置管理** - 日志系统配置页面
  - 🔍 **日志查询** - 日志查询和查看页面
  - 📊 **性能监控** - 实时性能监控面板

### 2.2 标签页切换
- 点击顶部导航或中间的标签页可以切换页面
- URL会同步更新（添加 `?tab=config/query/monitor` 参数）
- 支持书签直达指定页面
