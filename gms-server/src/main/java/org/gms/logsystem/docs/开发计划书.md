# 日志系统重构开发计划书

## 1. 项目概述

### 1.1 项目背景
当前日志系统存在以下问题：
1. 分类定义复杂，需要修改代码
2. 配置文件静态，无法动态调整
3. 缺乏完善的监控和配置管理界面
4. 用户信息筛选不够便捷
5. 大类小类选择不支持搜索

### 1.2 项目目标
重构日志系统，实现：
1. 动态分类管理
2. 全配置动态化
3. 完善的前端管理界面
4. 实时监控系统
5. 优化的查询体验
6. 大类小类下拉支持搜索

## 2. 技术架构

### 2.1 系统路径
- 后端：`org/gms/logsystem/`
- 前端：`gms-ui/src/views/game/logs/`
- API：`gms-ui/src/api/logs.ts`

### 2.2 核心组件
1. 动态配置管理（基于GameConfig）
2. 高性能日志记录器
3. 混合日志架构（Log4j2 + 自定义）
4. 实时监控系统
5. 前端管理界面

### 2.3 日志格式规范
基础日志信息以JSON格式存储，结构如下：
```json
{
  "t": "2025-11-20 20:08:26",      // 时间戳
  "v": "1.9.4",                    // 版本
  "lvl": "INFO",                   // 日志级别
  "hwid": "B6770000",              // 硬件ID
  "ip": "127.0.0.1",               // IP地址
  "mac": ["00-15-5D-C3-AE-64"],    // MAC地址
  "acc": "magical",                // 账号名
  "accId": 2,                      // 账号ID
  "chr": "Magical",                // 角色名
  "chrId": 2,                      // 角色ID
  "map": "竞技场出口",             // 地图名
  "mid": 980010020,                // 地图ID
  "cf": {                          // 自定义JSON数据
    "details": "由最终调用方法构造"
  }
}
```

## 5. 代码规范要求

### 5.1 日志输出规范
- 源码中的日志输出内容应**以中文为主**
- 避免混合中英文，保持统一的日志风格
- 示例：
  ```java
  log.warn("无效的分类信息: {}", categoryInfo);
  log.info("分类已注册: {} -> {}", categoryId, categoryInfo);
  log.error("未找到分类: {}.{}", majorCategory, minorCategory);
  ```

### 5.2 日志内容构造规范
- 日志内容通过final对象（`cf`字段）传递自定义JSON数据
- 由调用方法构造具体的业务数据
- 日志包含的基本信息字段：时间、版本、级别、硬件ID、IP、MAC、账号、角色、地图等
- 自定义数据以JSON格式组织，确保结构化存储

## 9. 当前不足之处 - 缺失模块功能详情

详见新建文档：**缺失模块功能清单.md**

### 9.1 前端页面无法正常显示的原因

#### LogQuery.vue 日志查询页面（无法显示日志）
**根本原因**：缺少日志查询API实现
- ❌ 缺失：`POST /api/logsystem/query` - 日志查询接口
- ❌ 缺失：`GET /api/logsystem/categories/all` - 分类列表接口  
- ❌ 缺失：`POST /api/logsystem/export/csv` - 导出功能
- **依赖服务**：LogQueryService、LogFileManager、日志索引
- **影响**：无法查询、筛选、导出日志数据

#### LogMonitor.vue 监控页面（部分数据为空）
**部分API缺失**：
- ❌ `GET /api/logsystem/monitor/queue` - 队列深度统计
- ❌ `GET /api/logsystem/monitor/context` - 活跃上下文统计
- ⚠️ `GET /api/logsystem/monitor/trend` - 性能趋势（API参数设计有问题）
- **依赖服务**：MonitorDataService、LogContextManager
- **影响**：队列统计、上下文、性能趋势数据无法显示

#### LogConfig.vue 配置页面（部分功能缺失）
- ❌ `DELETE /api/logsystem/config/packet/in-block/{opcode}` - 删除入站屏蔽
- ❌ `DELETE /api/logsystem/config/packet/out-block/{opcode}` - 删除出站屏蔽
- **影响**：网络包屏蔽列表无法删除
