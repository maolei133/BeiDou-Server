# gms-ui 前端项目结构分析

## 1. 目录结构

`gms-ui` 是一个基于 Vue 3 + TypeScript + Vite 的前端项目，主要用于管理冒险岛服务端。

### 根目录
- `src/`: 源代码目录
- `config/`: 配置文件目录
- `public/`: 静态资源目录 (index.html, favicon.ico)
- `package.json`: 项目依赖和脚本配置
- `tsconfig.json`: TypeScript 配置文件
- `vite.config.ts`: Vite 构建配置 (假设存在，虽然未列出但通常会有)
- `.env.*`: 环境变量配置

### src 目录
- `api/`: 后端接口定义，封装了 Axios 请求
- `assets/`: 静态资源（图片、样式等）
- `components/`: 公共组件
- `config/`: 项目内配置
- `directive/`: 自定义指令
- `hooks/`: Vue 组合式 API 钩子
- `layout/`: 页面布局组件
- `locale/`: 国际化资源
- `mock/`: Mock 数据
- `router/`: 路由配置
- `store/`: 状态管理 (Pinia/Vuex)
- `types/`: TypeScript 类型定义
- `utils/`: 工具函数
- `views/`: 页面视图组件
- `App.vue`: 根组件
- `main.ts`: 入口文件

## 2. 页面与后端 API 对应关系

下表展示了前端页面/模块与后端 API 的对应关系及作用。

| 模块/页面 | 对应 API 文件 | 主要功能 | 后端接口路径示例 |
| :--- | :--- | :--- | :--- |
| **用户认证** | `src/api/user.ts` | 登录、登出、获取用户信息、刷新 Token | `/auth/v1/login`, `/account/v1/info` |
| **账号管理** | `src/api/account.ts` | 账号列表、注册、封号/解封、GM修改账号信息 | `/account/v1`, `/account/v1/{id}/ban` |
| **角色管理** | `src/api/player.ts` | 在线角色列表、给予资源(物品/属性)、查询装备信息 | `/character/v1/online/list`, `/give/v1/resource` |
| **仪表盘** | `src/api/dashboard.ts` | 服务器状态查询、启动/停止/重启服务器 | `/server/v1/online`, `/server/v1/stopServerWithMsgAndInternal` |
| **掉落管理** | `src/api/drop.ts` | 怪物掉落、全局掉落的增删改查 | `/drop/v1/getDropList`, `/drop/v1/addDropData` |
| **商城管理** | `src/api/cashShop.ts` | 现金商城商品管理、上下架、分类查询 | `/cashShop/v1/getCommodityByCategory`, `/cashShop/v1/onSale` |
| **NPC商店** | `src/api/npcShop.ts` | NPC商店物品管理、增删改查 | `/shop/v1/getShopList`, `/shop/v1/addShopItem` |
| **扭蛋机** | `src/api/gachapon.ts` | 扭蛋机奖池及奖励管理 | `/gachapon/v1/getPools`, `/gachapon/v1/updateReward` |
| **背包管理** | `src/api/inventory.ts` | 玩家背包查询、物品修改/删除 | `/inventory/v1/getInventoryList`, `/inventory/v1/updateInventory` |
| **日志系统** | `src/api/logs.ts`<br>`src/api/logsystem.ts` | 系统日志查询、监控统计、配置管理、备份管理 | `/logsystem/logs/query`, `/logsystem/monitor/performance` |
| **信息查询** | `src/api/information.ts` | 通用信息搜索 (ID/名称/描述) | `/common/v1/informationSearch` |
| **文件管理** | `src/api/fileTree.ts` | 服务端文件树浏览、读写文件 | `/file/v1/tree`, `/file/v1/tree/read` |
| **指令管理** | `src/api/command.ts` | GM指令列表、权限修改、重载数据 | `/command/v1/getCommandListFromDB`, `/command/v1/reloadMapsByGMCommand` |
| **消息通知** | `src/api/message.ts` | 系统消息、聊天记录查询 | `/api/message/list`, `/api/chat/list` |
| **配置管理** | `src/api/config.ts` | 服务端配置项管理、导入/导出 YML | `/config/v1/getConfigList`, `/config/v1/updateConfig` |

### 详细 API 接口列表

#### 用户认证 (User)
| 接口方法 | 请求路径 | 作用 |
| :--- | :--- | :--- |
| `login` | POST `/auth/v1/login` | 用户登录 |
| `logout` | DELETE `/auth/v1/logout` | 用户登出 |
| `getUserInfo` | GET `/account/v1/info` | 获取当前用户信息 |
| `getMenuList` | GET `/account/v1/menu` | 获取菜单列表 |
| `refreshToken` | GET `/auth/v1/refreshToken` | 刷新 Token |

#### 账号管理 (Account)
| 接口方法 | 请求路径 | 作用 |
| :--- | :--- | :--- |
| `getAccountList` | GET `/account/v1` | 获取账号列表 (支持分页和筛选) |
| `addAccount` | POST `/account/v1` | 注册新账号 |
| `updateAccountByGM` | PUT `/account/v1/{id}` | GM更新账号信息 |
| `deleteAccount` | DELETE `/account/v1/{id}` | 删除账号 |
| `banAccount` | PUT `/account/v1/{id}/ban` | 封禁账号 |
| `unbanAccount` | PUT `/account/v1/{id}/unban` | 解封账号 |
| `resetLoggedIn` | PUT `/account/v1/{id}/reset/logged` | 重置登录状态 |

#### 仪表盘 (Dashboard)
| 接口方法 | 请求路径 | 作用 |
| :--- | :--- | :--- |

| `restartServer` | GET `/server/v1/restartServer` | 重启服务器 |
