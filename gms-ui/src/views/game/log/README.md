# 日志管理系统使用说明

## 功能概述

日志管理系统提供了对服务器日志的查询和分析功能，支持按以下条件进行筛选：

1. 日志大类（如：player、item、economy等）
2. 日志小类（如：login、logout、obtain等）
3. 时间范围（开始日期和结束日期）
4. 关键词搜索

## 使用方法

### 1. 基本查询

- 选择日志大类和小类进行分类查询
- 输入关键词进行内容搜索
- 设置时间范围筛选特定时间段的日志

### 2. 查询操作

点击"查询"按钮执行查询操作，系统将根据设置的条件筛选日志并显示在下方表格中。

## 日志分类说明

### 大类（Major Categories）
- player: 玩家相关日志
- item: 物品相关日志
- economy: 经济相关日志
- system: 系统相关日志
- chat: 聊天相关日志
- battle: 战斗相关日志
- quest: 任务相关日志
- shop: 商城相关日志
- social: 社交相关日志
- gm_command: GM命令相关日志
- error: 错误相关日志
- security: 安全相关日志

### 小类（Minor Categories）
每个大类下有不同的小类，例如：
- player/login: 玩家登录
- player/logout: 玩家登出
- item/obtain: 物品获得
- item/consume: 物品消耗
- economy/trade: 交易记录

## 注意事项

1. 日志数据量可能较大，请合理设置查询条件以提高查询效率
2. 关键词搜索支持模糊匹配
3. 查询结果按时间倒序排列（最新的日志在最前面）
